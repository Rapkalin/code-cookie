# Thème Code Cookie

Thème maison, **hybride** : les gabarits sont du PHP classique, le design est
piloté par `theme.json`. Transposé du gabarit `~/Sites/game-france`
(`steamulo-theme`), à l'échelle d'un blog de 32 articles.

- [Structure du dossier](readme/structure.md)
- [Styles (SCSS)](readme/styles.md)
- [Jetons et theme.json](readme/theme-json.md)
- [Le lexique de l'interface](readme/lexique.md)

## Démarrer

```
npm install
npm run watch:css
```

> ⚠️ `style.css` est **généré**. Toute modification à la main sera écrasée.
